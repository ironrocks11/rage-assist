# 🎮 Rage Assist

A browser-based game built with **JavaScript, Phaser, Vite, and Firebase**.

## 🎮 Live Demo

**Play the game:** https://rage-assist.web.app

## ✨ Features

* Browser-based gameplay
* Phaser-powered game engine
* Firebase Authentication
* Player login/signup
* Game progress handling
* Responsive web interface
* Vite-powered development and build workflow

## 🛠️ Tech Stack

* **JavaScript**
* **Phaser**
* **Vite**
* **Firebase Authentication**
* **HTML/CSS**

## 🤖 AI-Assisted Development

This project was developed using **AI-assisted programming and prompt engineering**.

AI tools were used during development to:

* Generate and iterate on code
* Explore and implement game features
* Debug implementation issues
* Refine the game and user experience

The development process involved directing the implementation through prompts, integrating generated code, testing features, debugging issues, and deploying the application.

## 🚀 Run Locally

Clone the repository:

```bash
git clone https://github.com/ironrocks11/rage-assist.git
```

Open the project:

```bash
cd rage-assist
```

Install dependencies:

```bash
npm install
```

Start the Vite development server:

```bash
npx vite
```

Then open the local URL shown in the terminal.
